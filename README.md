# Система учета личных финансов

Учебный проект по курсу «Разработка веб-приложений с использованием технологий ASP.NET Core».

Выполнил: Карим

## Стек технологий
- **Backend:** ASP.NET Core 8 (MVC), C#
- **База данных:** Entity Framework Core, SQLite
- **Безопасность:** ASP.NET Core Identity (регистрация, аутентификация, хеширование паролей)
- **Frontend:** Bootstrap 5, Bootstrap Icons, Chart.js

## Быстрый старт

1. Склонировать репозиторий:
   ```bash
   git clone https://github.com/dxusx/FinanceTracker.git
   cd FinanceTracker
   ```

2. Запустить проект:
   ```bash
   dotnet run
   ```
   *При первом запуске база данных `finance.db` и таблицы создадутся автоматически через миграции EF Core.*

3. Открыть браузер и перейти по адресу `http://localhost:5142` (или `https://localhost:7142`).

4. Войти под готовым студенческим профилем:
   - **Логин:** `student@mail.ru`
   - **Пароль:** `Student123!`
   *(или нажать **Регистрация** и создать свой новый аккаунт)*

## Основной функционал

- **Учет доходов и расходов:** добавление записей с указанием суммы, даты, категории и комментария.
- **Категории:** предустановленные базовые категории (зарплата, еда, транспорт и т.д.) плюс возможность создавать свои персональные категории с выбором типа и цвета.
- **Фильтрация и поиск:** просмотр операций по диапазону дат, конкретной категории, типу операции или тексту заметки.
- **Аналитика (Дашборд):** круговые диаграммы структуры расходов/доходов и динамика за последние месяцы (Chart.js).
- **Бюджетирование:** установка месячных лимитов по выбранным категориям расходов с прогресс-баром затрат.
- **Темы оформления:** светлая и темная тема с сохранением предпочтения в localStorage.
